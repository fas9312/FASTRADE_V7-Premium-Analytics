# FasTrade V7 — Premium Analytics Edition

Versione basata sulla V6 stabile, con interfaccia ridisegnata in stile trading/fintech e nuova area Analytics nella sezione Statistiche.

## Novità V7
- UI premium dark con gradienti, card compatte, glow discreto e header dinamici
- Home con hero Current Bank e mini sparkline KPI
- Grafico bankroll migliorato con valori asse Y, date dinamiche e callout finale
- Statistiche con nuova scheda Panoramica
- Grafico combinato Bankroll / Profitto cumulativo
- Grafico profitto per strategia
- Distribuzione profitto a ciambella
- Form Nuova Operazione più compatto e vicino al mockup
- Diario ridisegnato con badge WIN/LOSE e righe più compatte
- Schermata strumenti con CSV, Backup, Ripristino Dati, Impostazioni e firma
- Cancellazione depositi/prelievi mantenuta
- Intervalli 7G / 1M / 3M / 1A mantenuti

Database e funzioni della V6 restano compatibili.

## Novità V8 — Controllo rischio e gestione dati
- Avviso obbligatorio al raggiungimento di 3 loss consecutive, con invito a fare una pausa di 10 minuti
- Azzeramento completo di tutti i dati con doppia conferma
- Importazione ed esportazione backup separate e chiaramente identificate
- Esportazione delle operazioni in un file Excel `.xls`
